# Визуальная версия пака

Распакуйте папку `afterparty` в `packs/`. Для обновления существующего пака замените его `pack.json` и добавьте новые JPG в `media/`; все десять мемов также включены.

Изменения:
- Раунд 1: «Алло, техподдержка?» заменена на «Что это вблизи?».
- Раунд 2: сериалы заменены на «Объявления с Авито», песни — на «Тень наводит».
- В каждом визуальном вопросе поле `image` показывает загадку, `answerImage` — предмет целиком.
- Картинки — созданные imagegen фотоиллюстрации и силуэты, а не документальные макрофотографии. Изображение-ответ иллюстрирует тип предмета и может показывать другую модель.
- Финал расширен до 7 тем по запросу. В FORMAT.md рекомендовано 2–4 темы; структура массива сохранена. Отображение семи тем и вычёркивание нужно проверить в вашей игре: исходников приложения здесь нет.
- В каждом раунде ровно один кот и один аукцион. Все особые вопросы текстовые.
- Кот раунда 1: «Фармацевт объясняет — 2», 400; аукцион: «Вакансия мечты», 400.
- Кот раунда 2: «Объявления с Авито», 1000; аукцион: «Корзина подозрительного человека», 800.
- Видео сохранены без изменений, со звуком; вопрос отключает звук через `videoMuted`, ответ включает тот же файл через `answerVideo`.
- Ответы мемов перенесены из названий присланных файлов; засчитывайте узнаваемую фразу, не требуя точной пунктуации.

Проверено: структура JSON, цены, 50 вопросов, 7 финальных тем, все пути медиа, целостность JPG и ZIP. После загрузки выполните `npm run check` в своём проекте и откройте финал для проверки размещения семи тем.

`QUESTIONS.md` содержит вопросы и ответы для ведущего.
