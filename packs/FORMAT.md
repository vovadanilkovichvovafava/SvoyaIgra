# Формат пака для «Своей игры»

Пак — это один файл `pack.json` (UTF-8) плюс папка `media/` с картинками, видео и аудио.
Лежит в `packs/<имя-пака>/`.

## Структура

```json
{
  "title": "С днём рождения, Маша!",
  "subtitle": "Праздничный выпуск",
  "modifiersPerRound": 2,
  "neutralModifiersPerRound": 1,

  "rounds": [
    {
      "name": "Раунд 1",
      "themes": [
        {
          "name": "Название темы",
          "questions": [
            { "price": 100, "text": "Текст вопроса", "answer": "Правильный ответ" },
            { "price": 200, "text": "…", "answer": "…" },
            { "price": 300, "text": "…", "answer": "…" },
            { "price": 400, "text": "…", "answer": "…" },
            { "price": 500, "text": "…", "answer": "…" }
          ]
        }
      ]
    }
  ],

  "final": {
    "themes": [
      { "name": "Тема финала", "question": { "text": "Вопрос финала", "answer": "Ответ" } }
    ]
  },

  "finale": {
    "title": "С днём рождения, Маша!",
    "message": "Текст поздравления, который покажется в самом конце.\nМожно в несколько строк.",
    "image": "media/finale.jpg"
  }
}
```

## Правила

- Обычно **2 раунда**, в каждом **5 тем** по **5 вопросов**.
- Во всех темах одного раунда должно быть **одинаковое число вопросов** (иначе табло съедет).
- Цены: раунд 1 — `100, 200, 300, 400, 500`; раунд 2 — `200, 400, 600, 800, 1000`; раунд 3 (если есть) — `300, 600, 900, 1200, 1500`. Сложнее вопрос — дороже.
- Финал: 2–4 темы, у каждой один вопрос. Игроки по очереди убирают темы, на оставшуюся делают ставки
  и пишут ответ на телефоне.
- `answer` — коротко, как ведущий прочитает вслух. Пояснение можно вынести в `comment`.
- Тексты показываются ЗАГЛАВНЫМИ буквами на синем экране, поэтому вопросы лучше до ~150 символов.

## Поля вопроса

| Поле | Обязательно | Что это |
|---|---|---|
| `price` | да | цена |
| `text` | да | текст вопроса |
| `answer` | да | правильный ответ |
| `comment` | нет | пояснение под ответом (интересный факт, источник) |
| `image` | нет | картинка к вопросу: `"media/имя.jpg"` |
| `video` | нет | видео к вопросу: `"media/имя.mp4"` (H.264) |
| `videoMuted` | нет | `true` — видео в вопросе без звука и по кругу (угадать фразу), со звуком — в ответе |
| `audio` | нет | звук к вопросу: `"media/имя.mp3"` |
| `answerImage` / `answerVideo` / `answerAudio` | нет | медиа, которое покажется вместе с ответом |
| `type` | нет | особый вопрос, см. ниже (по умолчанию обычный) |
| `catTheme` | для кота | тема «кота в мешке» (своя, не как у строки табло) |
| `modifier` | нет | `"none"` — никогда не ставить модификатор на этот вопрос |

## Особые вопросы (`type`)

- `"cat"` — **Кот в мешке**: выбравший отдаёт вопрос другому игроку. Нужно поле `catTheme`.
- `"auction"` — **Аукцион**: игроки торгуются ставками, отвечает тот, кто поставил больше.
- `"stake"` — **Вопрос со ставкой**: выбравший сам ставит и сам отвечает.

Рекомендация: в раунде 1–2 кота и 1 аукцион, не больше. Ставить их на обычные текстовые вопросы
(не на вопросы с видео/музыкой).

## Модификаторы

Не нужно прописывать в вопросах — игра сама прячет их в случайные ячейки
(сколько — `modifiersPerRound` поровну положительных/отрицательных и `neutralModifiersPerRound` нейтральных).

Можно задать раунду точный набор: `"modifiers": ["double", "minus"]` — они лягут в случайные обычные вопросы
этого раунда, а `modifiersPerRound` / `neutralModifiersPerRound` для него не используются. Только так выпадают
`swapLeader` (🤝 Рокировка), `swapLast` (🔀 Обмен с последним) и `minus` (➖ Плюс на минус). Список — в `modifiers.js`.

## Примеры вопросов

```json
{ "price": 300, "text": "Итальянский десерт, название которого переводится как «подними меня».", "answer": "Тирамису" }

{ "price": 200, "text": "Из какого фильма этот кадр?", "image": "media/kino1.jpg", "answer": "«Дьявол носит Prada»" }

{ "price": 400, "text": "Видео без звука. Какую фразу говорят?", "video": "media/meme2.mp4", "videoMuted": true,
  "answer": "«Давай мясо, давай мясо!»", "answerVideo": "media/meme2.mp4" }

{ "price": 600, "text": "Назовите песню по вступлению", "audio": "media/song3.mp3", "answer": "Звери — «Районы-кварталы»" }

{ "price": 400, "type": "cat", "catTheme": "Мультфильмы", "text": "Как зовут кота из Простоквашино?", "answer": "Матроскин" }

{ "price": 800, "type": "auction", "text": "Где Маша больше всего мечтает побывать?", "answer": "В Японии" }
```

## Медиафайлы

- Кладутся в `packs/<имя-пака>/media/`, в `pack.json` пишутся как `"media/имя.расширение"`.
- Имена файлов — латиницей, без пробелов: `kino1.jpg`, `meme3.mp4`, `song2.mp3`.
- Картинки — JPG до ~500 КБ; видео — MP4 (H.264), короткие; аудио — MP3, 10–20 секунд.

Проверить пак: `npm run check` — покажет, что не заполнено и каких файлов не хватает.
