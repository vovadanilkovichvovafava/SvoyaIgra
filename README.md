# 🎂 Своя игра — праздничный выпуск

Веб-версия «Своей игры»: 1 ведущий + до 8 игроков с телефонов — каждый сам за себя или командами.

## Запуск

```
npm install     # один раз
npm start
```

В терминале появятся ссылки:
- **Ведущий** — `http://localhost:3000/host` (на ноутбуке; тут видны правильные ответы)
- **Экран** — `/screen` (по желанию: вывести на ТВ, ответов там не видно)
- **Игроки** — сканируют QR-код с экрана ведущего (телефоны в том же Wi‑Fi)

## Игра по ссылке (игроки где угодно)

```
npm run online
```

Через несколько секунд в терминале и в лобби ведущего появится ссылка вида
`https://что-то-там.trycloudflare.com/play`. Нажми «Скопировать ссылку» и отправь её всем:
игрок открывает ссылку, вводит имя и сразу оказывается в игре.

- Ссылка новая при каждом запуске, так что отправляй её уже в день игры, после `npm run online`.
- Ноутбук должен быть включён и не засыпать всю игру.
- Если играете не в одной комнате, созвонитесь (Telegram/Discord/Zoom), чтобы слышать ведущего.
  Табло, вопросы, музыка и картинки видны на телефонах, а выбирающий нажимает вопрос у себя сам.
- Страница ведущего по публичной ссылке закрыта. Открыть её с другого устройства можно только по ссылке
  с ключом из терминала (`…/host?key=…`).

## Режимы

В лобби ведущий выбирает режим (до 8 человек в любом):
- **Каждый сам за себя** — у каждого свои очки.
- **Команды** — 2–4 команды (названия можно поменять). Игрок выбирает команду на телефоне,
  ведущий может переставить людей или нажать «🎲 Перемешать». Очки общие на команду; кнопку может нажать
  любой из команды — отвечает команда. Кот в мешке, аукцион, модификаторы и финал разыгрываются между командами,
  ставку и ответ в финале может отправить любой участник команды.

## Как играть
1. Игроки заходят по QR и вводят имена → ведущий жмёт «Начать игру».
2. Игрок, у которого «✋ выбирает», называет тему и цену → ведущий нажимает на клетку.
3. Ведущий читает вопрос → «🔔 Открыть кнопки» → кто первым нажал на телефоне, тот отвечает.
4. ✓ Верно: +очки, этот игрок выбирает дальше. ✗ Неверно: −очки, кнопки открываются для остальных.
5. Особые вопросы:
   - 🐱 «Кот в мешке» — выбравший обязан отдать вопрос другому игроку, отвечает только он.
   - 🔨 «Аукцион» — торгуются все по очереди с выбравшего (он обязан открыть торги, минимум — цена вопроса):
     поднять ставку, ва-банк или пас. Кому не хватает очков перебить — пасует автоматически.
     Последний не спасовавший отвечает за свою ставку. В паке: `"type": "auction"`.
   - 💰 «Вопрос со ставкой» — выбравший сам ставит и сам отвечает (`"type": "stake"`).
6. Финал: убираем темы → ставки и ответы с телефонов → ведущий проверяет → 🎉 поздравление с конфетти.

Очки можно поправить вручную (нажми на число очков у игрока справа), а ошибку ведущего отменить кнопкой «↶ Отменить» (Ctrl+Z).

**Правила, как в передаче:**
- Нажал кнопку раньше, чем ведущий её открыл, — фальстарт, кнопка блокируется на 1 секунду.
- Если за 10 секунд после открытия кнопок никто не нажал, показывается правильный ответ.
- На ответ идёт 15-секундный таймер (только для вида, решает ведущий).
- После нажатия видно, кто на сколько опоздал.
- Выбирающий игрок может сам нажать на вопрос в табло у себя на телефоне.
- Если игрок потерял телефон или почистил браузер, он вводит то же имя и возвращается со своими очками.

**Модификаторы.** В каждом раунде несколько ячеек табло — модификаторы вместо вопросов: положительных и отрицательных
поровну (по умолчанию 1+1) и нейтральные сверху (по умолчанию 1). Количество настраивается в лобби. На табло их не видно.
Открывается такая ячейка — на экране только «МОДИФИКАТОР», кнопки сразу открыты. Кто первым нажал, тот его забирает
(крутится рулетка), и сразу открывается вопрос этой ячейки: первым отвечает он, с модификатором
(«Перевёртыш» срабатывает сразу при нажатии). Ошибся — кнопки открываются остальным, уже без модификатора.
Никто не нажал за 10 секунд — модификатор сгорает, а вопрос разыгрывается как обычный.
Каждый модификатор выпадает за игру один раз: если его забрали, больше он не появится. Сгоревший может выпасть снова.

| Положительные | Отрицательные | Нейтральные |
|---|---|---|
| ✖️2 Двойные очки — верный ответ ×2 | 🌗 Половинка — верный ответ ×½ | 🦝 Воришка — очки забираются у лидера |
| 🎯 Примерно — засчитывается близкий ответ | Ⓜ️ Только на «М» — отвечать словами на букву М | 🔄 Перевёртыш — очки меняют знак (−500 ↔ +500) |
| 🤝 Рокировка — сразу меняешься очками с лидером* | 🔀 Обмен с последним — сразу меняешься очками с последним* | |
| | ➖ Плюс на минус — твои очки сразу становятся минусом* | |

\* Только если пак сам назвал их в раунде (`"modifiers": [...]`), случайно они не выпадают. Если лидер ловит «Рокировку»
(или последний — «Обмен с последним»), ничего не происходит.

Ведущий видит модификаторы заранее (значок на ячейке), а на кнопках «Верно/Неверно» уже посчитаны очки.
«Примерно» и «Только на М» очки не меняют — за правилом следит ведущий.
В паке можно задать модификатор вопросу вручную: `"modifier": "double"` (или `"random"`, или `"none"` — никогда).
Список и правила модификаторов — в `modifiers.js`.

**Горячие клавиши ведущего:** Пробел — открыть кнопки · Y — верно · N — неверно · R — показать ответ · Enter — к табло · Ctrl+Z — отменить.

**Потренироваться одному:** в лобби ведущего есть ссылки «Игрок 1…4». Каждая открывает отдельного игрока в новой вкладке.

## Пак вопросов
`packs/birthday/pack.json`. Всё, что помечено ✏️, нужно заполнить.
Фото и музыку кладите в `packs/birthday/media/` (имена файлов указаны в pack.json).

Проверить, что осталось заполнить и каких файлов не хватает:
```
npm run check
```

Поля вопроса: `price`, `text`, `answer`, по желанию: `image`, `audio`, `video`, `answerImage`, `comment`,
`type` (`"cat"` + `catTheme` — кот в мешке, `"stake"` — вопрос со ставкой).

## Деплой на хостинг

Проект готов для любого хостинга Node.js. Выбери способ, который поддерживает твоя платформа:

- **Docker** (большинство современных платформ): в корне есть `Dockerfile`. Платформа сама соберёт образ.
- **Node.js-приложение из GitHub**: сборка `npm install` (или `npm ci`), запуск `npm start`. Node.js 18+.
- **Procfile** (хостинги в стиле Heroku): `web: node server.js`.

Настройки:

| Что | Значение |
|---|---|
| Переменная `HOST_KEY` | **обязательно**: пароль ведущего, страница `/host` попросит его |
| Переменная `PORT` | обычно задаёт сам хостинг (по умолчанию 3000) |
| Переменная `PUBLIC_URL` | необязательно: адрес сайта для ссылки и QR, если сам определяется неправильно |
| Проверка здоровья (health check) | `/health` (отвечает `ok`) |
| WebSocket | должен быть включён (на нём работают кнопки) |
| Количество экземпляров | **1**: игра хранит состояние в памяти |

Перезапуск или передеплой сбрасывает текущую игру, поэтому не обновляй приложение во время партии.
Пример переменных — в `.env.example`.

Игроки заходят по адресу `https://<твой-домен>/play`. Ссылка и QR-код показываются в лобби ведущего.
