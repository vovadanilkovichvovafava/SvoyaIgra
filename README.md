# 🎂 Своя игра — праздничный выпуск

Веб-версия «Своей игры»: 1 ведущий + до 4 игроков с телефонов.

## Запуск

```
npm install     # один раз
npm start
```

В терминале появятся ссылки:
- **Ведущий** — `http://localhost:3000/host` (на ноутбуке; тут видны правильные ответы)
- **Экран** — `/screen` (по желанию: вывести на ТВ, ответов там не видно)
- **Игроки** — сканируют QR-код с экрана ведущего (телефоны в том же Wi‑Fi)

## Игра по ссылке (игроки где угодно)

```
npm run online
```

Через несколько секунд в терминале и в лобби ведущего появится ссылка вида
`https://что-то-там.trycloudflare.com/play`. Нажми «Скопировать ссылку» и отправь её всем:
игрок открывает ссылку, вводит имя и сразу оказывается в игре.

- Ссылка новая при каждом запуске, так что отправляй её уже в день игры, после `npm run online`.
- Ноутбук должен быть включён и не засыпать всю игру.
- Если играете не в одной комнате, созвонитесь (Telegram/Discord/Zoom), чтобы слышать ведущего.
  Табло, вопросы, музыка и картинки видны на телефонах, а выбирающий нажимает вопрос у себя сам.
- Страница ведущего по публичной ссылке закрыта. Открыть её с другого устройства можно только по ссылке
  с ключом из терминала (`…/host?key=…`).

## Как играть
1. Игроки заходят по QR и вводят имена → ведущий жмёт «Начать игру».
2. Игрок, у которого «✋ выбирает», называет тему и цену → ведущий нажимает на клетку.
3. Ведущий читает вопрос → «🔔 Открыть кнопки» → кто первым нажал на телефоне, тот отвечает.
4. ✓ Верно: +очки, этот игрок выбирает дальше. ✗ Неверно: −очки, кнопки открываются для остальных.
5. Особые вопросы: 🐱 «Кот в мешке» (отдаётся другому игроку), 💰 «Вопрос со ставкой».
6. Финал: убираем темы → ставки и ответы с телефонов → ведущий проверяет → 🎉 поздравление с конфетти.

Очки можно поправить вручную (нажми на число очков у игрока справа), а ошибку ведущего отменить кнопкой «↶ Отменить» (Ctrl+Z).

**Правила, как в передаче:**
- Нажал кнопку раньше, чем ведущий её открыл, — фальстарт, кнопка блокируется на 1 секунду.
- Если за 10 секунд после открытия кнопок никто не нажал, показывается правильный ответ.
- На ответ идёт 15-секундный таймер (только для вида, решает ведущий).
- После нажатия видно, кто на сколько опоздал.
- Выбирающий игрок может сам нажать на вопрос в табло у себя на телефоне.
- Если игрок потерял телефон или почистил браузер, он вводит то же имя и возвращается со своими очками.

**Модификаторы.** В каждом раунде в случайных вопросах спрятаны модификаторы, хороших и плохих поровну
(сколько — настраивается в лобби, по умолчанию 4). На табло их не видно. Когда такой вопрос открывается, все видят
«🎲 В вопросе модификатор!», но какой — узнаёт только тот, кто первым нажмёт кнопку: крутится рулетка.
Действует только на этого игрока и только на его ответ.

| Хорошие | Плохие |
|---|---|
| ✖️2 Двойные очки — верный ответ ×2 | 💣 Минное поле — ошибка ×2 |
| 💎 Джекпот — верный ответ ×3 | 🌗 Половинка — верный ответ ×½ |
| 🛡️ Страховка — ошибка ничего не стоит | 🧾 Налог — сразу − половина цены |
| 🎁 Подарок — сразу + половина цены | |
| 🦝 Воришка — очки забираются у лидера | |

Ведущий видит модификаторы заранее (значок на ячейке), а на кнопках «Верно/Неверно» уже посчитаны очки.
В паке можно задать модификатор вопросу вручную: `"modifier": "double"` (или `"random"`, или `"none"` — никогда),
а также 🎲 «Всё или ничего» (`"allin"`, ×2 в обе стороны) — он выпадает только так.
Список и правила модификаторов — в `modifiers.js`.

**Горячие клавиши ведущего:** Пробел — открыть кнопки · Y — верно · N — неверно · R — показать ответ · Enter — к табло · Ctrl+Z — отменить.

**Потренироваться одному:** в лобби ведущего есть ссылки «Игрок 1…4». Каждая открывает отдельного игрока в новой вкладке.

## Пак вопросов
`packs/birthday/pack.json`. Всё, что помечено ✏️, нужно заполнить.
Фото и музыку кладите в `packs/birthday/media/` (имена файлов указаны в pack.json).

Проверить, что осталось заполнить и каких файлов не хватает:
```
npm run check
```

Поля вопроса: `price`, `text`, `answer`, по желанию: `image`, `audio`, `video`, `answerImage`, `comment`,
`type` (`"cat"` + `catTheme` — кот в мешке, `"stake"` — вопрос со ставкой).

## Деплой на хостинг

Подойдёт любой хостинг для Node.js с поддержкой WebSocket.

- Сборка: `npm install`
- Запуск: `npm start`
- Порт берётся из переменной `PORT` (хостинг обычно задаёт её сам).
- **Обязательно** задай переменную окружения `HOST_KEY`: это пароль ведущего.
  На странице `/host` игра попросит его ввести. Без ключа управлять игрой нельзя.
- Нужен **1 экземпляр** приложения: состояние игры хранится в памяти.
  Перезапуск сервера сбрасывает игру.

Игроки заходят по адресу `https://<твой-домен>/play`. Ссылка и QR-код показываются в лобби ведущего.
